Module 1: Introduction to CSS3

CSS = Cascading Style Sheets — controls how HTML elements LOOK.

CONCEPT Need & Benefits of CSS

  • Separation of concerns: HTML = structure, CSS = presentation, JS = behavior
  • Reusability: One stylesheet styles hundreds of pages
  • Maintainability: Change a brand color in ONE place; updates everywhere
  • Smaller pages: No repeated style attributes
  • Responsive design: Same HTML adapts to any screen size

SYNTAX CSS Rule Anatomy

CSS rule
selector { property: value; /* declaration */ color: red; font-size: 16px; } /* This is a CSS comment */
  • Selector: Which elements to style
  • Property: What aspect (color, margin)
  • Value: What to set it to
  • Declaration: property + value pair, ends with ;

METHODS 3 Ways to Include CSS

1. Inline (avoid)
<p style="color: red; font-size: 16px;">Red text</p>
2. Embedded (in <head>)
<style> p { color: red; } </style>
3. External (BEST)
<link rel="stylesheet" href="styles.css">
MethodSpecificityUse Case
InlineHighest (1000)Quick test or JS-set styles
EmbeddedMediumSingle-page styles
ExternalMedium✅ Production — recommended

SYNTAX CSS Comments

CSS uses ONLY /* ... */ comments — no // single-line:

Practice Q&A — Introduction

Q1What does CSS stand for, and what's its main purpose?
Answer: CSS = Cascading Style Sheets. Controls the PRESENTATION of HTML — colors, fonts, spacing, layout, animations. "Cascading" means styles can come from multiple sources and cascade based on specificity rules.
Q2Name the 3 ways to add CSS to HTML, and which is best.
Answer:
  1. Inline: style="..." attribute. Highest specificity, hard to maintain.
  2. Embedded: <style> in <head>. OK for single-page.
  3. External: <link rel="stylesheet">. ✅ Best — reusable, cacheable, maintainable.
Q3Write CSS to make all paragraphs blue with 18px font.
Answer: 
p {
  color: blue;
  font-size: 18px;
}
Q4What's the comment syntax in CSS?
Answer: /* comment */ only. CSS does NOT support // single-line comments. Both single and multi-line use /* ... */.
Q5If inline, embedded, and external CSS all set p { color } — which wins?
Answer: Inline wins (specificity 1000). Otherwise, the rule that comes LATER in document order wins. Specificity: inline (1000) > ID (100) > class/pseudo (10) > element (1).
Q6List 4 benefits of external CSS over inline.
Answer:
  1. Reusable — one CSS styles all pages.
  2. Cacheable — browser downloads once.
  3. Maintainable — change in one place.
  4. Separation of concerns — keeps HTML clean.

Module 2: CSS3 Selectors

How to target the elements you want to style.

BASIC 5 Essential Selectors

Basic selectors
/* 1. Universal — matches EVERYTHING */ * { margin: 0; } /* 2. Element/Type — all of that tag */ p { color: gray; } /* 3. ID — # — UNIQUE element */ #header { background: black; } /* 4. Class — . — multiple elements */ .btn { padding: 10px; } .btn.primary { background: blue; } /* 5. Grouping — apply to many */ h1, h2, h3 { font-family: serif; }

COMBO Combinator Selectors

Combinators
/* Descendant — <a> INSIDE .nav, any depth */ .nav a { color: white; } /* Child — DIRECT child only */ ul > li { list-style: none; } /* Adjacent sibling — IMMEDIATELY after */ h2 + p { font-weight: bold; } /* General sibling — ANY following sibling */ h2 ~ p { color: gray; }

PSEUDO Pseudo-classes & Pseudo-elements

Pseudo selectors
/* Pseudo-classes (single colon) — STATE */ a:hover { color: red; } input:focus { outline: 2px solid blue; } li:first-child { font-weight: bold; } li:nth-child(2n) { background: #eee; } /* Pseudo-elements (double colon) — VIRTUAL parts */ p::first-line { font-weight: bold; } p::first-letter { font-size: 2em; } .icon::before { content: "★"; }

CRITICAL Specificity — Which Rule Wins?

Selector typeScoreExample
Inline style1000style="..."
ID100#header
Class / attribute / pseudo-class10.btn, :hover
Element / pseudo-element1p, ::before
Universal0*

If specificity is tied, the LATER rule wins.

⚠️ !important overrides everything. Use sparingly: color: red !important;

Practice Q&A — Selectors

Q1What does * do in CSS?
Answer: Universal selector — matches EVERY element. Often used to reset: 
* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}
Q2How do you select by id "main"? By class "card"?
Answer:
  • By id: #main { ... } (hash prefix)
  • By class: .card { ... } (dot prefix)
Q3How do you apply the same style to h1, h2, h3 in one rule?
Answer: Use a grouping selector: 
h1, h2, h3 {
  font-family: 'Georgia', serif;
  color: navy;
}
Q4Difference between .nav a and .nav > a?
Answer:
  • .nav a — descendant: any <a> inside .nav, any depth.
  • .nav > a — child: only DIRECT children.
Example: <div class="nav"><ul><li><a></a></li></ul></div> — .nav a matches; .nav > a does NOT.
Q5Which has higher specificity: #main or .container.card?
Answer: #main wins (100) over .container.card (20). An ID always beats any number of classes.
Q6What does li:nth-child(2n) select?
Answer: Every EVEN <li> (2nd, 4th, 6th). Useful for striped tables.

Variants:
  • :nth-child(odd) or :nth-child(2n+1) — odd
  • :nth-child(3) — exactly the 3rd
  • :nth-child(3n) — every 3rd
Q7Difference between :hover and ::before?
Answer:
  • :hover — pseudo-class, single colon, targets a STATE of an element.
  • ::before — pseudo-element, double colon, creates a VIRTUAL element.
Pseudo-elements need a content property (can be empty "").

Module 3: Styling — Colors, Fonts, Text, Lists, Tables

The core visual properties you'll use every day.

COLORS CSS Color Values

5 ways to write color
.box { color: red; /* 1. Named */ color: #ff0000; /* 2. Hex (long) */ color: #f00; /* 3. Hex (short) */ color: rgb(255, 0, 0); /* 4. RGB */ color: rgba(255, 0, 0, 0.5); /* 5. RGBA (alpha) */ color: hsl(0, 100%, 50%); /* 6. HSL */ }

BG CSS Background

Background
.hero { background-color: #333; background-image: url('hero.jpg'); background-repeat: no-repeat; background-position: center center; background-size: cover; background-attachment: fixed; /* Or all in one shorthand: */ background: #333 url('hero.jpg') no-repeat center/cover; /* Linear gradient */ background: linear-gradient(to right, red, blue); }

FONTS CSS Fonts

Font properties
body { font-family: 'Helvetica', Arial, sans-serif; font-size: 16px; font-weight: 400; font-style: italic; line-height: 1.6; letter-spacing: 0.5px; }
Font fallback chain: List fonts in order of preference. Browser tries each until found. Always end with a generic family (serif, sans-serif, monospace).

TEXT CSS Text

Text properties
.article { text-align: center; text-decoration: underline; text-transform: uppercase; text-indent: 2em; text-shadow: 2px 2px 4px rgba(0,0,0,0.3); white-space: nowrap; word-break: break-word; }

LINKS CSS Link States (LoVe HAte)

Links have 4 STATES — order matters!

Link states
a:link { color: blue; } /* unvisited */ a:visited { color: purple; } /* visited */ a:hover { color: red; } /* mouse over */ a:active { color: orange; } /* during click */
Mnemonic: LoVe HAte → Link, Visited, Hover, Active.

LISTS CSS Lists

List styling
ul { list-style-type: square; /* disc | circle | square | none */ list-style-position: inside; /* inside | outside */ list-style-image: url('bullet.png'); } ol { list-style-type: decimal; /* 1, 2, 3 */ /* lower-alpha (a,b,c), upper-roman (I,II,III) */ }

TABLES CSS Tables

Table styling
table { border-collapse: collapse; /* merges cell borders */ width: 100%; } th, td { border: 1px solid #ddd; padding: 8px; text-align: left; } tr:nth-child(even) { background-color: #f9f9f9; /* zebra stripes */ }

Practice Q&A — Styling

Q1List 4 ways to specify a color in CSS.
Answer:
  1. Named: red, cornflowerblue
  2. Hex: #ff0000 or short #f00
  3. RGB: rgb(255, 0, 0) or rgba(255, 0, 0, 0.5)
  4. HSL: hsl(0, 100%, 50%) or hsla(...)
Q2What's the difference between background-size: cover and contain?
Answer:
  • cover — fills entire container, may CROP. Used for hero images.
  • contain — entire image visible, may leave EMPTY SPACE. Used for logos.
Q3What's the correct order for link pseudo-classes and why?
Answer: Link → Visited → Hover → Active (LoVe HAte).

CSS specificity ties go to LATER rule. If :hover comes before :visited, visited overrides hover. The "LVHA" order ensures all states display correctly.
Q4Why use a font fallback chain like 'Helvetica', Arial, sans-serif?
Answer: Not every user has every font. Browser tries each in order:
  1. Try Helvetica (Mac users)
  2. If not, try Arial (Windows users)
  3. If neither, use ANY sans-serif font
Always end with a generic family (serif, sans-serif, monospace) as final fallback.
Q5How do you create alternating row colors (zebra stripes) in a table?
Answer: 
tr:nth-child(even) {
  background-color: #f5f5f5;
}
:nth-child() with even or 2n targets every 2nd row.
Q6What does border-collapse: collapse do?
Answer: Merges adjacent table cell borders into single shared borders, removing the default double-border look. Without it, each cell has its own border with gaps between them.
Q7Difference between color and background-color?
Answer:
  • color — sets the FOREGROUND text color.
  • background-color — sets the BACKGROUND color of the element.

Module 4: CSS Box Model

The most important CSS concept — every element is a box made of 4 layers.

CRITICAL The Box Model

Every HTML element is a rectangular box composed of 4 layers (from inside out):

  1. Content — actual text, image, etc.
  2. Padding — space INSIDE the border (background color shows here)
  3. Border — line around padding
  4. Margin — space OUTSIDE the border (transparent, separates from other elements)
Box model visualization
┌─────── margin ────────┐ │ ┌──── border ────┐ │ │ │ ┌─ padding ─┐ │ │ │ │ │ content │ │ │ │ │ └───────────┘ │ │ │ └────────────────┘ │ └───────────────────────┘

PROPS Margin & Padding

Shorthand
/* All sides */ margin: 10px; /* Vertical | Horizontal */ margin: 10px 20px; /* Top | Horizontal | Bottom */ margin: 10px 20px 30px; /* Top | Right | Bottom | Left (clockwise) */ margin: 10px 20px 30px 40px; /* Individual sides */ margin-top: 10px; margin-right: 20px; margin-bottom: 30px; margin-left: 40px; /* Center horizontally */ margin: 0 auto;

padding works exactly the same way — same shorthand rules.

PROPS Border

Border properties
.box { /* Shorthand: width | style | color */ border: 2px solid red; /* Individual properties */ border-width: 2px; border-style: solid; /* solid | dashed | dotted | double | none */ border-color: red; border-radius: 8px; /* rounded corners */ /* Per-side */ border-top: 2px solid red; border-bottom: 1px dashed gray; }

PROPS Outline (Often Confused with Border)

AspectBorderOutline
Takes up space?✅ Yes — affects box size❌ No — drawn OVER element
Per-side control?✅ Yes (border-top, etc.)❌ No — all 4 sides at once
Border-radius?✅ Yes❌ Not always

Outline
input:focus { outline: 2px solid blue; outline-offset: 2px; /* gap between outline and element */ }

CRITICAL box-sizing — content-box vs border-box

The KEY question: when you set width: 200px, does padding/border ADD to the width?

content-box (default)border-box (modern)
width includesJust contentContent + padding + border
width: 200px + padding: 20px =240px total width200px total width
Best forOld code✅ Modern layouts (predictable)
Modern reset
*, *::before, *::after { box-sizing: border-box; }
Best practice: Apply border-box globally. Now width: 50% always means 50% — no math gymnastics.

LAYOUT Multiple Columns

CSS3 added native multi-column layout — like newspapers:

Multi-column
.article { column-count: 3; /* exact number */ column-width: 200px; /* min width per column */ column-gap: 2em; /* space between columns */ column-rule: 1px solid #ccc; /* divider line */ /* Shorthand */ columns: 3 200px; }

Practice Q&A — Box Model

Q1What are the 4 layers of the CSS box model (inside-out)?
Answer:
  1. Content — text, image, etc.
  2. Padding — space INSIDE the border (background shows here).
  3. Border — line around the padding.
  4. Margin — space OUTSIDE the border (transparent).
Q2What's the difference between margin and padding?
Answer:
  • Padding — space INSIDE the border. Background color extends into padding.
  • Margin — space OUTSIDE the border. Always transparent. Pushes other elements away.
Q3What does margin: 10px 20px 30px 40px mean?
Answer: 4 values are clockwise from top: Top, Right, Bottom, Left. So:
  • top: 10px, right: 20px, bottom: 30px, left: 40px
Mnemonic: TRBL ("trouble"). Same applies to padding and border-width.
Q4How do you center a block element horizontally?
Answer: 
.element {
  width: 600px;        /* must have explicit width */
  margin: 0 auto;      /* auto on left & right */
}
The auto tells browser to distribute remaining horizontal space equally on both sides.
Q5Difference between border and outline?
Answer:
  • Border — TAKES UP SPACE, affects element's actual size. Per-side control. Supports border-radius.
  • Outline — Drawn OVER the element, doesn't affect layout. All 4 sides at once. Often used for focus indicators.
Q6If you set width: 200px and padding: 20px, what's the actual width?
Answer: Depends on box-sizing:
  • content-box (default): 200 (content) + 40 (padding both sides) = 240px total
  • border-box: Total stays at 200px — content shrinks to 160px to accommodate padding
Modern best practice: use * { box-sizing: border-box; } for predictable sizing.
Q7Difference between display: none, visibility: hidden, and opacity: 0?
Answer:
  • display: none — Element completely REMOVED. No space taken.
  • visibility: hidden — Element invisible but space RESERVED (empty gap).
  • opacity: 0 — Transparent, but still INTERACTABLE (clickable, takes space).
Q8How do you create rounded corners?
Answer: 
.box {
  border-radius: 8px;       /* all corners */
  border-radius: 50%;       /* perfect circle */
  border-radius: 8px 16px;  /* top-left/bottom-right | top-right/bottom-left */
}
Works without a visible border too — affects the background and any borders.
Q9How do you split content into 3 columns like a newspaper?
Answer: 
.article {
  column-count: 3;
  column-gap: 2em;
  column-rule: 1px solid #ccc;
}
Text flows automatically across columns. Browser handles the splitting.

Module 5: Media Queries & Responsive Design

Make your site adapt to phones, tablets, and desktops.

CONCEPT What is Responsive Web Design (RWD)?

Responsive Web Design is an approach where web pages adapt their layout to fit any screen size — phones, tablets, laptops, big monitors — using a single codebase.

Three pillars of RWD:

  1. Fluid grids — use percentages (width: 50%) instead of fixed pixels
  2. Flexible images — max-width: 100% so images shrink with container
  3. Media queries — apply different CSS at different screen sizes

SETUP Viewport Meta Tag (Required!)

Without this, mobile browsers render at 980px wide and zoom out — your responsive CSS WON'T work.

In <head>
<meta name="viewport" content="width=device-width, initial-scale=1.0">
  • width=device-width — page width matches device width
  • initial-scale=1.0 — no zoom on load

SYNTAX Media Queries

Media query syntax
/* Apply styles only on screens 768px or wider */ @media (min-width: 768px) { .container { width: 750px; } } /* Styles for screens 768px or smaller */ @media (max-width: 768px) { .sidebar { display: none; } } /* Range — between 768 and 1024 */ @media (min-width: 768px) and (max-width: 1024px) { .tablet-only { display: block; } } /* Different media types */ @media screen and (orientation: landscape) { ... } @media print { ... } /* styles when printing */

BREAKPOINTS Common Breakpoints

DeviceWidthCommon Breakpoint
Mobile (phones)320 - 575pxmax-width: 575px
Tablet576 - 767pxmin-width: 576px
Small laptop768 - 991pxmin-width: 768px
Desktop992 - 1199pxmin-width: 992px
Large desktop1200px+min-width: 1200px
Mobile-first approach: Write base styles for mobile, then use min-width to ADD styles for larger screens. This is faster and cleaner than designing desktop-first.

PATTERN Mobile-First Example

Mobile-first pattern
/* Mobile (default - no media query) */ .container { width: 100%; padding: 10px; } .sidebar { display: none; /* hidden on mobile */ } /* Tablet and up */ @media (min-width: 768px) { .container { width: 750px; margin: 0 auto; } .sidebar { display: block; } } /* Desktop and up */ @media (min-width: 992px) { .container { width: 970px; } }

Practice Q&A — Responsive Design

Q1What is Responsive Web Design (RWD)?
Answer: An approach where web pages adapt their layout to fit ANY screen size using a single codebase. The 3 pillars are:
  1. Fluid grids (% widths)
  2. Flexible images (max-width: 100%)
  3. Media queries (different CSS per screen size)
Q2Why is the viewport meta tag required for mobile?
Answer: Without it, mobile browsers render the page at a virtual 980px width and zoom out — making your media queries ineffective. The tag tells the browser to use the device's actual width: 
<meta name="viewport" content="width=device-width, initial-scale=1.0">
Q3Write a media query that hides a sidebar on screens smaller than 768px.
Answer: 
@media (max-width: 767px) {
  .sidebar {
    display: none;
  }
}
Q4What's the difference between min-width and max-width in media queries?
Answer:
  • min-width: 768px — applies when screen is 768px OR LARGER (going up).
  • max-width: 768px — applies when screen is 768px OR SMALLER (going down).
Mobile-first approach uses min-width. Desktop-first uses max-width.
Q5What's the "mobile-first" approach and why is it preferred?
Answer: Write base CSS for mobile (smallest screen), then use min-width media queries to ADD styles for larger screens.

Why preferred:
  • Mobile is the most common device — get it right first
  • Forces you to prioritize content (less screen space)
  • Cleaner CSS — additive rather than overriding
  • Better performance on mobile (less CSS to parse)
Q6How do you make an image responsive?
Answer: 
img {
  max-width: 100%;
  height: auto;
}
max-width: 100% ensures it never overflows its container. height: auto maintains aspect ratio.
Q7Difference between em and rem?
Answer:
  • em — relative to PARENT'S font size. Compounds when nested.
  • rem — relative to ROOT (html) font size. Always consistent.
Example: if root is 16px and parent is 20px, 1em = 20px but 1rem = 16px. Use rem for predictable sizing.
Q8What's 1vw? When would you use it?
Answer: 1vw = 1% of viewport WIDTH. 1vh = 1% of viewport HEIGHT.

Use cases:
  • Full-screen hero sections: height: 100vh
  • Fluid hero text: font-size: 5vw (scales with screen)
