Module 1: Introduction to Bootstrap 5

The world's most popular CSS framework — get a polished site fast.

CONCEPT What is Bootstrap?

Bootstrap is a free, open-source CSS framework that gives you pre-built, responsive, mobile-first components by adding CSS classes to your HTML.

Bootstrap 5 (released 2021) — key changes from v4:

  • ✅ NO jQuery dependency — uses vanilla JavaScript
  • ✅ CSS custom properties (variables)
  • ✅ New xxl breakpoint (1400px)
  • ✅ RTL support, off-canvas component
  • ❌ Dropped IE support

SETUP CDN Setup (Easiest)

Bootstrap CDN
<!-- In <head> --> <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/css/bootstrap.min.css" rel="stylesheet"> <!-- Before </body> --> <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/js/bootstrap.bundle.min.js"></script>
The .bundle. version includes Popper.js (needed for tooltips/dropdowns).

SETUP NPM Setup

npm
$ npm install bootstrap // In your JS: import 'bootstrap/dist/css/bootstrap.min.css'; import 'bootstrap';

GRID Grid System Basics

Bootstrap uses a 12-column grid. Three nesting levels: container → row → col.

Basic grid
<div class="container"> <div class="row"> <div class="col">Col 1</div> <div class="col">Col 2</div> </div> </div>
  • container — fixed-width centered wrapper
  • row — flex group of columns
  • col — equal-width columns
  • col-6 — 6 of 12 (50% width)

Practice Q&A — Layout

Q1Difference between .container and .container-fluid?
Answer:
  • .container — fixed max-width per breakpoint, centered with margins.
  • .container-fluid — always 100% width, full edge-to-edge.
Q2List Bootstrap 5's 6 breakpoints.
Answer: xs (<576px), sm (≥576px), md (≥768px), lg (≥992px), xl (≥1200px), xxl (≥1400px — NEW in v5).
Q3What does col-md-6 mean?
Answer: "On medium screens (≥768px) and above, take 6 of 12 columns (50% width)." On smaller screens, stacks to full width.
Q4How to make a layout that's full-width on mobile and 3 columns on desktop?
Answer: 
<div class="row">
  <div class="col-12 col-md-4">Card 1</div>
  <div class="col-12 col-md-4">Card 2</div>
  <div class="col-12 col-md-4">Card 3</div>
</div>
Q5How to center items both horizontally and vertically?
Answer: 
<div class="d-flex justify-content-center align-items-center">
  <div>Centered</div>
</div>
Q6What does justify-content-between do?
Answer: Distributes flex items so the first is at the start, last is at the end, and equal space is between them. Common for navbar layouts.
Q7Can you nest a row inside a column?
Answer: Yes. The inner row gets a fresh 12-column grid based on the parent column's width. Common pattern for complex layouts.

Practice Q&A — Components

Q1List 5 button color variants in Bootstrap.
Answer: btn-primary, btn-secondary, btn-success, btn-danger, btn-warning, btn-info, btn-light, btn-dark. Add btn-outline-* for outlined versions.
Q2How do you create a small button?
Answer: Add btn-sm: <button class="btn btn-primary btn-sm">Small</button>. For large: btn-lg.
Q3What classes do form inputs need in Bootstrap?
Answer:
  • form-control — for <input> and <textarea>
  • form-select — for <select>
  • form-check-input — for checkboxes/radios
  • form-label — for labels
Q4How to make a navbar collapse on mobile?
Answer: Use navbar-expand-lg (collapses below lg breakpoint), then add a toggle button with data-bs-toggle="collapse" data-bs-target="#navId" matching the menu's id.
Q5Which data attribute opens a modal?
Answer: 
data-bs-toggle="modal"
data-bs-target="#modalId"
Note: Bootstrap 5 uses data-bs-* prefix (with "bs"). Bootstrap 4 used just data-*.
Q6How do you create a dismissible alert?
Answer: 
<div class="alert alert-info alert-dismissible fade show">
  Message
  <button class="btn-close" data-bs-dismiss="alert"></button>
</div>
The classes alert-dismissible fade show + a close button with data-bs-dismiss="alert".
Q7What's the difference between btn-primary and btn-outline-primary?
Answer:
  • btn-primary — solid filled button with primary color background.
  • btn-outline-primary — transparent background with primary-colored border and text. Fills on hover.

Practice Q&A — Utilities

Q1What does m-3 do?
Answer: Sets margin on all 4 sides at size 3 (1rem). Bootstrap spacing scale: 0=none, 1=0.25rem, 2=0.5rem, 3=1rem, 4=1.5rem, 5=3rem.
Q2Difference between mx-auto and my-auto?
Answer:
  • mx-auto — auto margin on x-axis (left and right) → centers HORIZONTALLY
  • my-auto — auto margin on y-axis (top and bottom) → centers VERTICALLY (only works in flex/grid containers)
Q3How do you hide an element on mobile but show on tablet+?
Answer: <div class="d-none d-md-block">
  • d-none — hidden by default (mobile)
  • d-md-block — display: block from md (768px) up
Q4What does py-3 mean?
Answer: Padding on Y-axis (top + bottom) at size 3 (1rem). p=padding, y=vertical, 3=size. px would be horizontal padding.
Q5How do you make text bold and red?
Answer: <p class="fw-bold text-danger">Important!</p>. fw-bold = font-weight bold, text-danger = red color (Bootstrap's danger semantic color).
Q6How do you make an element a perfect circle?
Answer: Add the class rounded-circle — typically used for avatar images: 
<img src="avatar.jpg" class="rounded-circle" width="80">
Element should have equal width & height for a perfect circle.
Q7What's the difference between start/end and left/right?
Answer: Bootstrap 5 uses start/end instead of left/right to support RTL (right-to-left) languages like Arabic and Hebrew. In RTL mode, start automatically becomes the right side. So ms-3 = margin-start = margin-left in LTR, margin-right in RTL.

Module 5: Responsive Design

Media queries, responsive images, and mobile-first navigation.

CONCEPT Mobile-First Approach

Bootstrap is built mobile-first. Default classes (no breakpoint prefix) apply to ALL screen sizes. Add breakpoint prefixes to OVERRIDE on larger screens.

Mobile-first pattern
<!-- Full width on mobile, half on tablet, third on desktop --> <div class="col-12 col-md-6 col-lg-4"></div> <!-- Small text mobile, large desktop --> <p class="fs-6 fs-md-4 fs-lg-2">Heading</p> <!-- Padding scales up on bigger screens --> <div class="p-2 p-md-4 p-lg-5"></div>

SETUP Required Viewport Meta Tag

Bootstrap requires this in your HTML <head> for responsive features to work:

Viewport
<meta name="viewport" content="width=device-width, initial-scale=1">
⚠️ Without this, mobile browsers will render at 980px wide and zoom out — breaking your responsive layout.

IMAGES Responsive Images

rounded-circlePerfect circle (for avatars)
Responsive images
<!-- Scales with container --> <img src="hero.jpg" class="img-fluid" alt="..."> <!-- Thumbnail with border --> <img src="pic.jpg" class="img-thumbnail"> <!-- Avatar (circular) --> <img src="avatar.jpg" class="rounded-circle" width="80">

NAV Building Responsive Navigation

The full responsive navbar pattern:

  • navbar-expand-lg — collapses below lg breakpoint
  • navbar-toggler — hamburger menu button (auto-shown when collapsed)
  • collapse navbar-collapse — the menu container that hides/shows
  • data-bs-toggle="collapse" — connects toggle button to menu

Other expand options: navbar-expand-sm, navbar-expand-md, navbar-expand-xl.

Practice Q&A — Responsive

Q1What does img-fluid do?
Answer: Applies max-width: 100%; height: auto — making images scale down with their container while maintaining aspect ratio. Essential for responsive images.
Q2What's the mobile-first approach in Bootstrap?
Answer: Default classes (no breakpoint prefix) apply to ALL screen sizes including the smallest (mobile). You add breakpoint prefixes (md-, lg-) only to OVERRIDE styles on larger screens.

Example: col-12 col-md-6 means full width on mobile (default), then half width from medium screens up.
Q3Why is the viewport meta tag required?
Answer: Without it, mobile browsers default to a virtual 980px width and zoom out — making your media queries and responsive classes ineffective. The tag tells browsers to use the device's actual width. 
<meta name="viewport" content="width=device-width, initial-scale=1">
Q4How do you make a circular avatar image?
Answer: 
<img src="avatar.jpg" class="rounded-circle" width="80" height="80">
Class rounded-circle creates a perfect circle. Image should have equal width and height for the circle to look right.
Q5What does navbar-expand-lg mean?
Answer: The navbar shows EXPANDED (full menu visible) at the lg breakpoint and ABOVE (≥992px). Below lg, it COLLAPSES into a hamburger menu.

Variants: navbar-expand-sm / md / xl / xxl. Without any size, navbar-expand means "always expanded".
Q6Difference between img-fluid and img-thumbnail?
Answer:
  • img-fluid — makes image scale responsively (max-width: 100%).
  • img-thumbnail — also responsive PLUS adds a 1px border, padding, and rounded corners. Thumbnail-style framed look.

Module 6: Customization & Extensions

Theming, icons, and SASS basics.

VARS CSS Variables (Bootstrap 5)

Bootstrap 5 exposes its design tokens as CSS custom properties — easy theming without rebuilding from source:

Override variables
/* In your CSS, AFTER Bootstrap is loaded */ :root { --bs-primary: #ff6b35; --bs-primary-rgb: 255, 107, 53; --bs-body-font-family: 'Inter', sans-serif; --bs-body-color: #222; --bs-border-radius: 12px; }

Now every btn-primary, text-primary, etc. uses your custom color.

ICONS Bootstrap Icons

Bootstrap Icons is a separate library (~2,000 free SVG icons). Add it via CDN:

Setup
<!-- In <head> --> <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/bootstrap-icons@1.11.0/font/bootstrap-icons.css"> <!-- Use anywhere as a font icon --> <i class="bi bi-heart-fill"></i> <i class="bi bi-search"></i> <i class="bi bi-trash"></i> <!-- In a button --> <button class="btn btn-primary"> <i class="bi bi-download"></i> Download </button>

Browse all icons at icons.getbootstrap.com.

SASS Introduction to SASS

SASS (Syntactically Awesome Style Sheets) is a CSS preprocessor that adds variables, nesting, mixins, and functions. Bootstrap is BUILT in SASS — using it lets you customize at the source level.

Custom Bootstrap with SASS
// custom.scss // 1. Override Bootstrap variables BEFORE importing $primary: #ff6b35; $body-bg: #f8f8f8; $border-radius: 12px; // 2. Import Bootstrap (or just the parts you need) @import "~bootstrap/scss/bootstrap"; // 3. Add your custom CSS below .my-component { color: $primary; }
Why SASS over CSS variables? CSS variables are runtime — only certain things are themable. SASS variables are compile-time — you can override anything Bootstrap uses internally, and unused parts get tree-shaken.

Practice Q&A — Customization

Q1How do you customize Bootstrap's primary color without using SASS?
Answer: Override the CSS custom property in your own stylesheet (loaded AFTER Bootstrap): 
:root {
  --bs-primary: #ff6b35;
  --bs-primary-rgb: 255, 107, 53;
}
Now btn-primary, text-primary, bg-primary all use your color.
Q2What is Bootstrap Icons?
Answer: A free SVG icon library (~2,000 icons) developed by Bootstrap. Loaded separately from Bootstrap CSS. Use icons by adding classes like bi bi-heart, bi bi-search: 
<i class="bi bi-heart-fill"></i>
Q3What is SASS?
Answer: SASS (Syntactically Awesome Style Sheets) is a CSS preprocessor that adds:
  • Variables — $primary: blue;
  • Nesting — write rules inside other rules
  • Mixins — reusable rule blocks
  • Functions, partials, imports
SASS files (.scss) are compiled to plain CSS. Bootstrap is built in SASS.
Q4Difference between customizing Bootstrap with CSS variables vs SASS?
Answer:
  • CSS variables (--bs-*): Easier setup. Runtime customization. Limited to what Bootstrap exposes as variables. Loaded CSS includes everything.
  • SASS: Requires build setup. Compile-time. Override ANY Bootstrap internal variable. Can selectively import only the components you use (smaller output).
Use CSS variables for quick theming. Use SASS for production builds or deep customization.
Q5Write the SASS code to set Bootstrap's primary color to orange.
Answer: 
// custom.scss
$primary: #ff6b35;

@import "bootstrap/scss/bootstrap";
⚠️ The override MUST come BEFORE the @import. After Bootstrap loads, $primary is already set internally.
Q6How do you put a Bootstrap Icon inside a button?
Answer: 
<button class="btn btn-primary">
  <i class="bi bi-download"></i> Download
</button>
Use <i> with the bi bi-{name} classes. The icon inherits the button's color.
