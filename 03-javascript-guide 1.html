Module 1: Introduction to JavaScript

The programming language of the web. Adds interactivity to HTML.

CONCEPT What is JavaScript?

JavaScript (JS) is a high-level, interpreted programming language that runs in web browsers (and on servers via Node.js). It's the THIRD pillar of web development:

  • HTML — structure
  • CSS — appearance
  • JavaScript — behavior & interactivity
Despite the name, JavaScript has nothing to do with Java. It was named for marketing reasons in 1995 when Java was popular. The official standardized name is ECMAScript.

SETUP Setting Up the Environment

JavaScript runs in any modern browser — no installation needed for client-side code.

  • Browser: Open DevTools Console (F12) → type JS directly
  • Code editor: VS Code with Live Server extension
  • Node.js (optional): Run JS outside the browser, on your computer

METHODS 3 Ways to Embed JavaScript

1. Inline (avoid)
<button onclick="alert('Hi')">Click</button>
2. Internal (in <script> tag)
<script> console.log('Hello'); </script>
3. External (BEST)
<script src="app.js" defer></script>

Use defer so the script loads in parallel but runs AFTER HTML is parsed. Or place <script> tags at the end of <body>.

Practice Q&A — Introduction

Q1What is JavaScript and what does it do?
Answer: JavaScript is a programming language that runs in web browsers. It adds INTERACTIVITY and BEHAVIOR to web pages — handling clicks, validating forms, fetching data from APIs, animating elements. It's the third pillar of the web alongside HTML (structure) and CSS (style).
Q2Is JavaScript related to Java?
Answer: NO. Despite the name, they're completely different languages. JavaScript was originally called "LiveScript" but renamed for marketing in 1995 when Java was popular. The official standardized name is ECMAScript.
Q3Name 3 ways to embed JavaScript in HTML.
Answer:
  1. Inline: onclick="..." attributes (avoid in production)
  2. Internal: <script> tag in HTML
  3. External: <script src="app.js" defer></script> ✅ Best
Q4Why use defer on script tags?
Answer: defer tells the browser to:
  1. Download the script in parallel with HTML parsing (no blocking)
  2. Execute it ONLY after HTML is fully parsed
This means your script can safely access DOM elements without checking if they exist yet.

Practice Q&A — Basics

Q1What's the difference between let, const, and var?
Answer:
  • const — block-scoped, CANNOT be reassigned. ✅ Use by default.
  • let — block-scoped, CAN be reassigned. Use when you need to reassign.
  • var — function-scoped (older), can be reassigned. ❌ Avoid in modern code.
Block scope means a variable only exists within { } braces. var ignores blocks, causing bugs.
Q2What's the difference between == and ===?
Answer:
  • == — loose equality. Performs TYPE COERCION (converts types). 5 == '5' is true.
  • === — strict equality. Both VALUE and TYPE must match. 5 === '5' is false.
Always use === to avoid bugs. Same for !== instead of !=.
Q3List the 7 primitive data types in JavaScript.
Answer:
  1. String — 'hello'
  2. Number — 42, 3.14
  3. Boolean — true/false
  4. null — intentional empty
  5. undefined — not assigned
  6. Symbol — unique identifiers
  7. BigInt — huge integers
Plus Object (which includes Array, Function, etc.) — but that's not a primitive.
Q4Difference between null and undefined?
Answer:
  • undefined — variable declared but not assigned. JavaScript sets this automatically.
  • null — explicitly assigned by developer to mean "intentionally empty/no value".
let x;          // x is undefined
let y = null;   // y is null (intentional)
Q5Write a function that adds two numbers, using arrow syntax.
Answer: 
const add = (a, b) => a + b;

// Or with explicit return:
const add = (a, b) => {
  return a + b;
};
Q6What does the modulo operator % do?
Answer: Returns the REMAINDER after division. 
10 % 3   // 1 (10 ÷ 3 = 3 remainder 1)
8 % 2    // 0 (even number — useful for parity check!)
17 % 5   // 2
Common use: check if a number is even with n % 2 === 0.
Q7What's a template literal?
Answer: A string syntax using BACKTICKS that allows variable interpolation and multi-line strings: 
const name = 'Alice';
const age = 30;

// Old way (concatenation)
const msg1 = 'Hi ' + name + ', age ' + age;

// Template literal (modern)
const msg2 = `Hi ${name}, age ${age}`;

// Multi-line works naturally
const html = `<div>
  Content
</div>`;

Module 3: DOM Manipulation & Events

How JavaScript reads and modifies HTML — the heart of interactive web pages.

CONCEPT What is the DOM?

DOM (Document Object Model) represents the page as a TREE of nodes. JavaScript can read and modify this tree to change the page dynamically.

DOM tree
document └── html ├── head │ └── title └── body ├── h1 └── p └── "Hello"

SELECT Selecting Elements

Selection methods
// By id (returns ONE element or null) const header = document.getElementById('main-header'); // querySelector (returns FIRST match — uses CSS selectors) const btn = document.querySelector('.btn'); const first = document.querySelector('#nav li:first-child'); // querySelectorAll (returns ALL matches as a NodeList) const items = document.querySelectorAll('.list-item'); items.forEach(item => console.log(item)); // Older methods (still work) document.getElementsByClassName('btn'); document.getElementsByTagName('p');
Modern recommendation: Use querySelector and querySelectorAll — they support full CSS selector syntax and are more flexible.

MODIFY Manipulating Elements

Reading & changing
// TEXT (safe — no HTML parsing) el.textContent = 'New text'; // HTML (parses tags — risky with user input!) el.innerHTML = '<b>Bold</b>'; // ATTRIBUTES img.src = 'pic.jpg'; link.href = '/about'; el.setAttribute('data-id', '42'); el.getAttribute('href'); // CSS CLASSES el.classList.add('active'); el.classList.remove('hidden'); el.classList.toggle('open'); el.classList.contains('active'); // returns boolean // INLINE STYLE el.style.color = 'red'; el.style.backgroundColor = '#fff'; // camelCase!
⚠️ innerHTML with user input is dangerous (XSS attack risk). Always use textContent for user-provided strings unless you've sanitized them.

CREATE Creating & Removing Elements

DOM modification
// Create const div = document.createElement('div'); div.textContent = 'Hello'; div.classList.add('card'); // Append (add as last child) document.body.appendChild(div); parent.append(div); // modern, can take strings too // Insert before another element parent.insertBefore(newEl, existingEl); // Remove el.remove();

EVENTS Event Handling

addEventListener
// Modern way (best) btn.addEventListener('click', function(event) { console.log('Clicked!'); event.preventDefault(); // stop default action }); // With arrow function btn.addEventListener('click', (e) => { console.log(e.target); // element that was clicked }); // Remove listener (must be a NAMED function) function handleClick() { ... } btn.addEventListener('click', handleClick); btn.removeEventListener('click', handleClick);

Practice Q&A — DOM & Events

Q1What is the DOM?
Answer: Document Object Model — a tree representation of the HTML page. Each HTML tag becomes a node in the tree. JavaScript reads and modifies this tree to change the page dynamically. The DOM is created by the browser when the page loads.
Q2What's the difference between getElementById and querySelector?
Answer:
  • getElementById('foo') — only finds by ID. Faster but limited.
  • querySelector('.foo') — uses ANY CSS selector. More flexible. Returns first match.
querySelector('#foo') is equivalent to getElementById('foo'). Modern code generally uses querySelector for consistency.
Q3Difference between textContent and innerHTML?
Answer:
  • textContent — treats input as plain text. '<b>Hi</b>' shows as literal text.
  • innerHTML — parses input as HTML. '<b>Hi</b>' shows as bold "Hi".
⚠️ Using innerHTML with user input creates XSS vulnerabilities. Use textContent for safety unless you've sanitized the input.
Q4How do you add a CSS class to an element?
Answer: 
el.classList.add('active');           // add
el.classList.remove('hidden');        // remove
el.classList.toggle('open');          // toggle on/off
el.classList.contains('active');      // check if has class
el.classList.replace('old', 'new');   // swap
Q5Why use addEventListener instead of onclick?
Answer:
  1. Multiple handlers — addEventListener allows MANY listeners per event. onclick only stores ONE.
  2. Removable — removeEventListener can detach later.
  3. Separation of concerns — keeps HTML clean.
  4. Capture phase — third argument controls event flow direction.
Q6What does event.preventDefault() do?
Answer: Stops the browser's DEFAULT action for that event.

Examples:
  • On a form submit: prevents the page from reloading
  • On a link click: prevents navigating to the URL
  • On a checkbox: prevents toggling
form.addEventListener('submit', (e) => {
  e.preventDefault();  // stop page reload
  // handle submission with JS
});
Q7How do you create a new <div> and add it to the body?
Answer: 
const div = document.createElement('div');
div.textContent = 'Hello';
div.classList.add('my-class');
document.body.appendChild(div);
Steps: create the element, set its content/attributes/classes, then append it to a parent in the DOM.

Module 4: Objects, Arrays & JSON

JavaScript's most-used data structures.

OBJECTS Working with Objects

Objects
// Create const user = { name: 'Alice', age: 30, greet() { console.log(`Hi, ${this.name}`); } // method }; // Access properties user.name; // "Alice" (dot notation) user['name']; // "Alice" (bracket notation) // Update / add properties user.age = 31; user.email = 'a@x.com'; // add new property // Delete a property delete user.email; // Loop through keys for (const key in user) { console.log(key, user[key]); } // Modern methods Object.keys(user); // ['name', 'age', 'greet'] Object.values(user); // ['Alice', 30, function] Object.entries(user); // [['name','Alice'], ['age',30], ...] // Destructuring const { name, age } = user; // Now: name === 'Alice', age === 30 // Spread operator (copy / merge) const copy = { ...user }; const updated = { ...user, age: 31 };

ARRAYS Working with Arrays

Arrays
// Create const fruits = ['apple', 'banana', 'cherry']; // Access (zero-indexed) fruits[0]; // 'apple' fruits.length; // 3 // Add / remove fruits.push('date'); // add to END fruits.pop(); // remove from END fruits.unshift('aprcot'); // add to START fruits.shift(); // remove from START // Find / search fruits.indexOf('banana'); // 1 fruits.includes('apple'); // true fruits.find(f => f.length > 5); // 'banana' // Iteration methods (modern, very common) fruits.forEach(f => console.log(f)); // map — transform each item const upper = fruits.map(f => f.toUpperCase()); // filter — keep matching items const long = fruits.filter(f => f.length > 5); // reduce — combine into single value const total = [1,2,3].reduce((sum, n) => sum + n, 0); // 6 // sort, reverse, slice, splice... fruits.sort(); fruits.slice(1, 3); // non-destructive copy fruits.splice(1, 1); // destructive remove

JSON JSON Basics

JSON (JavaScript Object Notation) is a text format for data exchange. Looks like JS objects but with strict rules:

  • Keys MUST be in double quotes
  • Strings must use double quotes (no single)
  • No comments, no functions, no undefined
  • Trailing commas are forbidden
JSON example
// JSON string (note: keys in double quotes!) const jsonStr = '{"name": "Alice", "age": 30, "active": true}'; // Parse JSON → JS object const obj = JSON.parse(jsonStr); console.log(obj.name); // "Alice" // Stringify JS object → JSON const str = JSON.stringify(obj); console.log(str); // '{"name":"Alice","age":30,...}' // Pretty-print with indent JSON.stringify(obj, null, 2);

Practice Q&A — Objects, Arrays & JSON

Q1How do you access object properties? Two ways.
Answer: 
const user = { name: 'Alice', age: 30 };

// 1. Dot notation (preferred when possible)
user.name;     // "Alice"

// 2. Bracket notation (needed for dynamic keys or special chars)
user['name'];  // "Alice"
const key = 'name';
user[key];     // "Alice"
Q2What does the spread operator ... do?
Answer: Spreads (expands) array/object contents. 
// Copy array
const copy = [...arr];

// Merge arrays
const combined = [...arr1, ...arr2];

// Copy object
const newUser = { ...user };

// Update object property (without mutating original)
const older = { ...user, age: user.age + 1 };

// Function arguments
Math.max(...[1, 2, 3]);  // 3
Q3Difference between map, filter, and forEach?
Answer:
  • forEach — runs a function for each item. Returns NOTHING (undefined). Just for side effects.
  • map — TRANSFORMS each item, returns a NEW array of same length.
  • filter — KEEPS items where callback returns true. Returns shorter array.
[1,2,3].forEach(n => console.log(n));     // logs 1, 2, 3
[1,2,3].map(n => n * 2);                  // [2, 4, 6]
[1,2,3].filter(n => n > 1);               // [2, 3]
Q4What's the difference between push/pop and shift/unshift?
Answer:
  • push(item) — adds to END
  • pop() — removes from END
  • shift() — removes from START
  • unshift(item) — adds to START
const arr = [2, 3];
arr.push(4);     // [2, 3, 4]
arr.unshift(1);  // [1, 2, 3, 4]
arr.pop();       // [1, 2, 3]
arr.shift();     // [2, 3]
Q5What does JSON.parse() do vs JSON.stringify()?
Answer:
  • JSON.parse(str) — converts a JSON STRING into a JavaScript OBJECT.
  • JSON.stringify(obj) — converts a JavaScript OBJECT into a JSON STRING.
const str = '{"name":"Alice"}';
const obj = JSON.parse(str);
console.log(obj.name);  // "Alice"

const back = JSON.stringify(obj);
console.log(back);  // '{"name":"Alice"}'
Use parse when receiving data from APIs or localStorage. Use stringify when sending data or saving.
Q6What's destructuring? Show an example.
Answer: A shortcut to extract values from objects/arrays into variables: 
// Object destructuring
const user = { name: 'Alice', age: 30 };
const { name, age } = user;
// name === 'Alice', age === 30

// With renaming
const { name: userName } = user;
// userName === 'Alice'

// Array destructuring
const [first, second] = [1, 2, 3];
// first === 1, second === 2

// In function parameters
function greet({ name }) {
  console.log(`Hi ${name}`);
}
greet(user);
Q7How do you check if an array contains a value?
Answer: 
const arr = ['apple', 'banana'];

// Modern (preferred)
arr.includes('apple');  // true

// Older
arr.indexOf('apple') !== -1;  // true

// For complex objects, use find
arr.find(x => x.id === 5);  // returns matching object or undefined

Module 5: Advanced JavaScript

Async, error handling, and ES6+ features.

ASYNC Asynchronous JavaScript

JavaScript runs single-threaded but can handle async tasks (network requests, timers) without blocking. Three approaches:

1. Callbacks (old)
setTimeout(() => { console.log('After 1 second'); }, 1000); // "Callback hell" - nested callbacks getData((err, data) => { processData(data, (err, result) => { saveData(result, ...); }); });
2. Promises (better)
fetch('/api/users') .then(response => response.json()) .then(data => console.log(data)) .catch(err => console.error(err)) .finally(() => console.log('Done'));
3. async/await (best — modern)
async function loadUsers() { try { const response = await fetch('/api/users'); const data = await response.json(); console.log(data); } catch (err) { console.error(err); } } loadUsers();
async/await is just syntactic sugar over Promises — but reads like normal sync code. Modern code uses this almost exclusively.

ERRORS Error Handling

try / catch / finally
try { const data = JSON.parse(badInput); // might throw console.log(data); } catch (error) { console.error('Failed:', error.message); } finally { console.log('Always runs'); } // Throw your own errors function divide(a, b) { if (b === 0) { throw new Error('Cannot divide by zero'); } return a / b; }

Practice Q&A — Advanced

Q1What is a Promise?
Answer: An object representing the eventual completion (or failure) of an asynchronous operation. Has 3 states:
  • Pending — initial state, not yet completed
  • Fulfilled — completed successfully (use .then())
  • Rejected — failed (use .catch())
fetch('/api')
  .then(res => res.json())
  .then(data => console.log(data))
  .catch(err => console.error(err));
Q2What's the difference between async/await and .then()?
Answer: Both handle Promises but differ in syntax:
  • .then() — chained methods. Functional style.
  • async/await — looks like synchronous code. Easier to read for sequential operations.
// .then chain
fetch('/api').then(r => r.json()).then(data => ...)

// async/await (same thing, cleaner)
async function load() {
  const r = await fetch('/api');
  const data = await r.json();
}
Note: await only works inside async functions.
Q3Why use try/catch?
Answer: To handle errors gracefully without crashing your code. 
try {
  // code that might fail
  const data = JSON.parse(badInput);
} catch (error) {
  // runs only if error thrown
  console.error('Parse failed:', error.message);
} finally {
  // always runs (cleanup, e.g., close file)
}
Without try/catch, a thrown error stops execution and breaks your app.
Q4List 5 ES6 features.
Answer:
  1. let / const — block-scoped variables
  2. Arrow functions — (a, b) => a + b
  3. Template literals — `Hello ${name}`
  4. Destructuring — const { x, y } = obj
  5. Spread/Rest operators — ...arr
  6. Default parameters, classes, modules, Promises
Q5What's the difference between throw and return?
Answer:
  • return value — exits function NORMALLY with that value.
  • throw error — exits function with an ERROR. Caller's code stops unless they have try/catch.
Use throw for error conditions that the caller must handle. Use return null for "absence" cases that aren't errors.
Q6How do you import a function from another module?
Answer: 
// math.js — exports
export function add(a, b) { return a + b; }
export const PI = 3.14;
export default function multiply(a, b) { return a*b; }

// app.js — imports
import multiply, { add, PI } from './math.js';
//      ↑ default        ↑ named imports

// Or import everything
import * as math from './math.js';
math.add(2, 3);
Note: HTML must use <script type="module"> for imports to work.
Q7What's a callback function?
Answer: A function passed AS AN ARGUMENT to another function, called later when something happens. 
// setTimeout takes a CALLBACK
setTimeout(function() {
  console.log('Runs after 1 second');
}, 1000);

// addEventListener takes a callback
btn.addEventListener('click', () => {
  console.log('Clicked!');
});
Callbacks were the original async pattern, now mostly replaced by Promises and async/await.
