Group 1 — Eureka Server (steps 1-3)

1
Eureka Server

Create the project

Why
We need this because without Eureka, services cannot find each other by name — they would have to hardcode addresses that break every time a service moves.
What to create

Go to start.spring.io. Set Artifact: eureka-server, Java 17, Maven. Add one dependency: Eureka Server. Generate, download, open in IDE.

Is this mandatory
YES — without Eureka, the Feign client in Order Service cannot resolve the name "product-service" to a real address.
Annotations needed
AnnotationWhat it doesStatus
None at project creation — skeleton is auto-generated.

Product Service

Product entity

Why
We need this because JPA needs a Java class to know what columns to create in the products table in MySQL.
What to create
product-service/src/main/java/com/ecommerce/productservice/model/Product.java
Is this mandatory
YES — without it there is no table and nothing to store.
Annotations needed
AnnotationWhat it doesStatus
@EntityTells JPA: map this class to a database table.MANDATORY
@Table(name="products")Sets the table name. If omitted, JPA uses the class name.OPTIONAL
@IdMarks the primary key field. JPA needs this to identify rows.MANDATORY
@GeneratedValueDatabase auto-generates the id (1, 2, 3...). Without it you set the id yourself.OPTIONAL
@ColumnCustomises a column (nullable, unique). Not needed for simple fields.OPTIONAL
Code
product-service/src/main/java/com/ecommerce/productservice/model/Product.java 
package com.ecommerce.productservice.model;
import jakarta.persistence.*;
import java.math.BigDecimal;

@Entity                     // MANDATORY: map this class to a DB table
@Table(name = "products")  // OPTIONAL: name the table "products"
public class Product {

    @Id                     // MANDATORY: this is the primary key
    @GeneratedValue(strategy = GenerationType.IDENTITY)  // DB auto-generates id
    private Long id;

    private String name;        // plain column, no annotation needed
    private BigDecimal price;   // plain column
    private Integer quantity;   // plain column

    public Product() {}         // JPA requires a no-argument constructor

    // getters and setters — required for JPA and JSON
    public Long getId()           { return id; }
    public String getName()       { return name; }
    public void setName(String n)  { this.name = n; }
    public BigDecimal getPrice()  { return price; }
    public void setPrice(BigDecimal p) { this.price = p; }
    public Integer getQuantity()  { return quantity; }
    public void setQuantity(Integer q) { this.quantity = q; }
}

AnnotationWhat it doesStatus

Code
product-service/src/main/java/com/ecommerce/productservice/service/ProductService.java 
package com.ecommerce.productservice.service;
import com.ecommerce.productservice.model.Product;
import com.ecommerce.productservice.repository.ProductRepository;
import org.springframework.stereotype.Service;
import java.util.List;

@Service  // MANDATORY: makes this a Spring-managed component
public class ProductService {

    private final ProductRepository repo;

    public ProductService(ProductRepository repo) {
        this.repo = repo;  // Spring injects the repository automatically
    }

    public List<Product> getAll()           { return repo.findAll(); }
    public Product getById(Long id)          { return repo.findById(id).orElseThrow(); }
    public Product save(Product p)           { return repo.save(p); }
    public void    delete(Long id)           { repo.deleteById(id); }
    public Product update(Long id, Product p) {
        Product existing = getById(id);
        existing.setName(p.getName());
        existing.setPrice(p.getPrice());
        existing.setQuantity(p.getQuantity());
        return repo.save(existing);
    }
}

product-service/src/main/java/com/ecommerce/productservice/controller/ProductController.java 
package com.ecommerce.productservice.controller;
import com.ecommerce.productservice.model.Product;
import com.ecommerce.productservice.service.ProductService;
import org.springframework.web.bind.annotation.*;
import java.util.List;

@RestController              // MANDATORY: marks as REST controller, returns JSON
@RequestMapping("/products") // OPTIONAL: prefix for all URLs below
public class ProductController {

    private final ProductService service;
    public ProductController(ProductService service) { this.service = service; }

    @GetMapping              // GET /products — list all
    public List<Product> all() { return service.getAll(); }

    @GetMapping("/{id}")     // GET /products/1 — get one
    public Product one(@PathVariable Long id) { return service.getById(id); }

    @PostMapping             // POST /products — create new
    public Product create(@RequestBody Product p) { return service.save(p); }

    @PutMapping("/{id}")    // PUT /products/1 — update
    public Product update(@PathVariable Long id, @RequestBody Product p) {
        return service.update(id, p);
    }

    @DeleteMapping("/{id}") // DELETE /products/1 — delete
    public void delete(@PathVariable Long id) { service.delete(id); }
}

13
Order Service

ProductResponse DTO

Why
We need this because when Feign calls Product Service and gets back JSON, it needs a local class to put that data into. This is a plain class — no database connection, no annotations.
What to create
order-service/src/main/java/com/ecommerce/orderservice/dto/ProductResponse.java
Is this mandatory
YES — Feign needs a local class to map the JSON response into. Without it, you cannot use the product data.
Annotations needed
AnnotationWhat it doesStatus
None at all. This is a plain Java class. No @Entity, no @Table, no database of any kind.
Why NOT copy the Product entity from product-service?

If you import the Product class from product-service, Order Service depends on product-service's code. If product-service changes its fields, Order Service breaks. Keep them independent: copy only the fields you need into this plain DTO class.

Code
order-service/src/main/java/com/ecommerce/orderservice/dto/ProductResponse.java 
package com.ecommerce.orderservice.dto;
import java.math.BigDecimal;

// Plain Java class. No annotations. No database connection.
// Only include the fields Order Service actually needs from the product.
public class ProductResponse {
    private Long id;
    private String name;
    private BigDecimal price;   // needed to calculate totalPrice

    public ProductResponse() {}
    public Long getId()           { return id; }
    public void setId(Long i)      { id = i; }
    public String getName()       { return name; }
    public void setName(String n)  { name = n; }
    public BigDecimal getPrice()  { return price; }
    public void setPrice(BigDecimal p) { price = p; }
}

14
Order Service — KEY STEP

ProductClient (Feign interface)

Why
We need this because this is how Order Service calls Product Service. You describe the call once in an interface — Feign builds the real HTTP call automatically. Uses Step 12 (@EnableFeignClients must already be on the main class).
What to create
order-service/src/main/java/com/ecommerce/orderservice/client/ProductClient.java
Is this mandatory
YES — this is the only way Order Service communicates with Product Service.
Annotations needed
AnnotationWhat it doesStatus
@FeignClient(name="product-service")Marks this interface as a caller. The name MUST exactly match spring.application.name in product-service's properties.MANDATORY
@GetMapping("/products/{id}")Tells Feign which URL on product-service to call. Must match the controller in Step 9.MANDATORY
@PathVariable("id")Fills the {id} placeholder in the URL with the method argument.MANDATORY
This is an INTERFACE, not a class

You do not write any implementation. Feign reads this interface at startup (because of @EnableFeignClients in Step 12) and builds the real HTTP code automatically. Calling productClient.getById(1L) sends a real GET request to product-service.

Code
order-service/src/main/java/com/ecommerce/orderservice/client/ProductClient.java 
package com.ecommerce.orderservice.client;
import com.ecommerce.orderservice.dto.ProductResponse;
import org.springframework.cloud.openfeign.FeignClient;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.PathVariable;

@FeignClient(name = "product-service")
// MANDATORY: name must match spring.application.name=product-service exactly
// Feign asks Eureka to resolve "product-service" to a real address — no port hardcoded
public interface ProductClient {

    @GetMapping("/products/{id}")
        // MANDATORY: the URL on product-service to call — must match ProductController step 9
    ProductResponse getById(@PathVariable("id") Long id);
        // @PathVariable("id"): fills {id} in the URL
    // Returns ProductResponse (our local DTO) — Feign converts the JSON automatically
}

order-service/src/main/java/com/ecommerce/orderservice/service/OrderService.java 
package com.ecommerce.orderservice.service;
import com.ecommerce.orderservice.client.ProductClient;
import com.ecommerce.orderservice.dto.ProductResponse;
import com.ecommerce.orderservice.model.Order;
import com.ecommerce.orderservice.repository.OrderRepository;
import org.springframework.stereotype.Service;
import java.util.List;

@Service  // MANDATORY
public class OrderService {

    private final OrderRepository repo;
    private final ProductClient productClient;
    // productClient looks like a normal object but every call goes over HTTP to product-service

    public OrderService(OrderRepository repo, ProductClient productClient) {
        this.repo = repo;
        this.productClient = productClient;
    }

    public List<Order> getAll()  { return repo.findAll(); }
    public Order getById(Long id) { return repo.findById(id).orElseThrow(); }

    public Order createOrder(Long productId, Integer quantity) {
        ProductResponse product = productClient.getById(productId);
        // This one line sends a real HTTP GET to http://product-service/products/{productId}
        // Feign handles the network call, JSON conversion, and error handling

        Order order = new Order();
        order.setProductId(productId);
        order.setQuantity(quantity);
        order.setTotalPrice(product.getPrice().multiply(
            java.math.BigDecimal.valueOf(quantity)));
        // totalPrice = price from product-service * quantity entered by user
        return repo.save(order);
    }

    public void delete(Long id) { repo.deleteById(id); }
}
